Scroll-film websites · art-directed, not templated

Describe a brand. Get one continuous film that scrolls.

Not a page with animations bolted on — a single journey from top to bottom, with a concept, a palette, a type pairing and copy written for that brand. It comes out as one self-contained file you download and host anywhere. No account, no builder to learn, no lock-in.

The part worth knowing: the model art-directs and writes, and the page itself is assembled by code. Scroll animation is unforgiving — get the order of a pinned scene wrong and everything below it silently lands in the wrong place — so that part is a tested renderer, not something improvised each time.

The brief

Your brief is used to design the site and then discarded. Nothing is stored and the text is never logged.

Name, what it does, who it is for, and the feeling. Mention colours, fonts or a journey if you have one in mind — or leave it and it will be art-directed for you.

How it gets made

Live preview — scroll inside it

What you get. One HTML file, self-contained apart from Google Fonts and the animation libraries it loads from a CDN. Put it on any host. It is a real starting point built to a real standard — reduced motion respected, a skip link past the film, contrast checked before it renders — and it is a starting point rather than a finished site. The words are yours to edit.

Why it is built this way

Taste from the model, structure from code

The model returns a design spec — concept, palette, type, journey, copy. A tested renderer turns that into the page. It never writes the HTML.

Because animation fails quietly

Pinned scenes must be created before ambient ones, or everything below a pin lands in the wrong place with no error. Code gets that right every time.

Checked before you see it

A palette whose text falls below 4.5:1, or four chapters using one motion, is rejected and rebuilt rather than shipped looking finished.

No template underneath

Two brands get two different worlds — different fonts, different palette, a different journey. There is no theme being re-skinned.

This is the engine. A site built properly — your words, your images, your domain, and the cinematic tier with real footage — starts with a conversation.
